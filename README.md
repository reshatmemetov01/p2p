# Игры для Яндекс Игр 🎮

Коллекция казуальных HTML5-игр для [Яндекс Игр](https://games.yandex.ru/).
Каждая игра — **отдельная папка и отдельный ZIP** для загрузки на площадку.

| Игра | Папка | Жанр |
|---|---|---|
| **2048: Суперсила** | `/` (корень) | Головоломка 2048 |
| **Блок Бласт** | `block-blast/` | Блоки 8×8 (Block Blast) |
| **Моя Ферма** | `garden/` | Ходилка-ферма (в духе Grow a Garden из Roblox) |

Обе на чистом JavaScript, лёгкие (~30 КБ), с подключённым Yandex Games SDK и
монетизацией через рекламу. Монетизация, SDK и способы заработка у них одинаковые
(см. ниже).

---

## 2048: Суперсила

Классика 2048 с изюминкой — **суперспособности** (Отмена, Бомба, Микс), которые
игрок активирует просмотром рекламы. Это и есть главный источник дохода.

Чистый JavaScript + DOM, без тяжёлых движков. Весит ~30 КБ → мгновенная
загрузка, что Яндекс любит и что повышает удержание.

## Фишки

- **Суперспособности за рекламу** ↩️💣🔀 — каждая открывается просмотром
  rewarded-ролика (самый дорогой вид рекламы).
- **Комбо-система** — несколько слияний за один ход дают растущий бонус с
  анимацией. Залипательно → больше времени в игре → больше показов рекламы.
- **«Продолжить за рекламу»** после проигрыша — освобождает место на поле.
- Свайпы на телефоне, стрелки/WASD на ПК, адаптивная вёрстка.
- Рекорд сохраняется между сессиями.

## Откуда деньги 💰

Рекламу показывает **сам Яндекс** через свою сеть — тебе не нужно искать
рекламодателей. Ты только расставил в коде «крючки», где показать рекламу:

| Где | Тип | Файл |
|---|---|---|
| Между партиями (кнопка «Новая игра») | Полноэкранная | `js/game.js` → `newGame()` |
| Суперспособности (Отмена/Бомба/Микс) | За награду | `js/game.js` → `doUndo/enterBombMode/doShuffle` |
| «Продолжить» после проигрыша | За награду | `js/game.js` → `continueAfterAd()` |

Яндекс берёт свою долю, остальное начисляет на твой счёт в кабинете
разработчика. Раз в месяц выводишь на карту. **Никаких ID вставлять не надо** —
реклама привязывается к аккаунту автоматически.

## Как залить на Яндекс Игры

> Каждая игра загружается отдельно. Для **2048** архивируй файлы из корня
> репозитория (`index.html`, `css/`, `js/`). Для **Блок Бласт** — содержимое
> папки `block-blast/`, для **Грядок** — содержимое папки `garden/`
> (каждый раз `index.html` должен быть в корне архива).

1. Зарегистрируйся как разработчик: <https://games.yandex.ru/console>
2. Создай новую игру, тип — **HTML5**.
3. Собери ZIP-архив из содержимого нужной папки (файл `index.html` должен быть в
   корне архива, а не внутри вложенной папки):
   - `index.html`, папки `css/` и `js/`.
4. Загрузи ZIP в консоль, заполни карточку (название, иконка, скриншоты,
   описание, категория — «Головоломки»).
5. Отправь на модерацию. Обычно 1–3 дня.
6. После публикации заходи в раздел «Монетизация» — там видно доход.

> SDK Яндекса (`js/yandex-sdk.js`) уже подключён. При запуске вне Яндекса
> (локально, двойным кликом по `index.html`) реклама просто пропускается, а
> награда за способности выдаётся сразу — удобно для тестов.

## Локальный запуск

Просто открой `index.html` в браузере. Для свайпов удобнее запустить простой
сервер:

```bash
python3 -m http.server 8000
# открой http://localhost:8000
```

## Структура

```
index.html          # разметка
css/style.css       # оформление (неоновая тема)
js/yandex-sdk.js    # обёртка над Yandex Games SDK (реклама)
js/game.js          # вся игровая логика
```

## Как делать новые игры на этой базе

Эта игра — шаблон для «конвейера». Чтобы выпустить новую:
1. Поменяй тему: цвета плиток в `css/style.css` (классы `.t2`…`.t2048`) и
   содержимое плиток (вместо чисел — эмодзи/картинки).
2. Оставь ту же механику рекламы.
3. Новый ZIP → новая карточка на Яндексе.

Доход на площадке идёт с количества игр: чем больше игр в каталоге, тем выше
шанс, что одна-две «выстрелят».
